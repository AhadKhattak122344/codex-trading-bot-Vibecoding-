# codex-trading-bot-Vibecoding

This repository now contains a beginner-friendly walkthrough for building a sentiment-driven demo trading bot (TradeSent.AI style) on Windows with VS Code, Alpaca paper trading, Reddit/Twitter ingestion, FinBERT sentiment, and Flask + Socket.IO glue code samples.

- Start with **docs/TradeSent_AI_getting_started.md** for step-by-step setup, including how to create each Python file inside VS Code.
- Install dependencies with `pip install -r requirements.txt` after activating your virtual environment.
